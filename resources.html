Getting started in research

1. Start with a question

Good projects start from a policy-relevant question you care about, not from a method. Read recent papers in the area, note what they leave open, and ask what data would let you answer it. When you are ready, write a one-page note: the question, why it matters, the data, and how you would identify the effect. Overleaf LaTeX templates are a good place to write it.

2. Learn causal inference
  • Causal Inference: The Mixtape (start here)
  • Introduction to Econometrics with R
  • Applied Empirical Methods (Ph.D. course)
  • Difference-in-differences resources (Pedro H. C. Sant'Anna)
  • Difference-in-differences course (Clément de Chaisemartin)
  • Staggered DiD software packages (Asjad Naqvi)
  • Difference-in-differences reading group
  • Online Causal Inference Seminar
  • Discrete Choice Methods with Simulation (for valuation and choice models)
3. Build your coding skills

Stata

  • Stata guides (University of Wisconsin–Madison)
  • Stata tutorials (Princeton University)
  • reghdfe: fast fixed-effects OLS and ppmlhdfe: fast fixed-effects Poisson
  • gtools: big data processing
  • Top 25 Stata visualizations with code

Python, R and machine learning

  • Stata to Python equivalents
  • Library of Statistical Techniques (LOST): the same method in Stata, R and Python
  • DoWhy and EconML (Python)
  • Economics and data science
  • Machine learning in economics
  • Knowledge-Guided Machine Learning (Karpatne, Kannan and Kumar, 2022): building scientific knowledge into ML models
4. Work with spatial and survey data
  • Spatial Thoughts blog (Ujaval Gandhi): GIS and Google Earth Engine tutorials
  • AidData GeoQuery: subnational data, ready to download
  • geoBoundaries: administrative boundaries
  • Automatic download and processing of DHS surveys
